# Insurance Prediction

This project predicts insurance charges based on user details.

## Features

- Takes user details as input
- Calculates BMI using height and weight
- Encodes categorical data
- Uses a trained Linear Regression model
- Predicts insurance charges

## Project Structure

- `main.py` - Runs the application
- `training.py` - Trains and saves the model
- `prediction.py` - Handles insurance prediction
- `app.py` - Handles the Streamlit application
- `models/` - Stores the trained model files

## How to Run

Run the following command from the project folder:

```bash
python -m streamlit run main.py
